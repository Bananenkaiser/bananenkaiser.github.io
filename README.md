# bananenkaiser.github.io

Persönliche Website von Dominik Tisleric, Data Scientist.

https://bananenkaiser.github.io/

## Aufbau

Eine statische Seite ohne Build-Schritt und ohne JavaScript, ausgeliefert über GitHub Pages.

- `index.html` – gesamte Seite inklusive CSS
- `assets/portrait.jpg`, `assets/portrait.webp` – Porträt in Webgröße
- `profilbild.jpg` – Originalfoto

## Lokal ansehen

`index.html` direkt im Browser öffnen oder:

```bash
python3 -m http.server
```
